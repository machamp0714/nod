# 反証の判定

## 担当と対象

- 役割: 反証
- 定義名: code-reviewer-refute
- 担当 ID: （分かれば。分からなければ「不明」）
- モデル申告: （自分で分かる情報と出典。分からなければ「未確認」）
- 対象版: 対象リポジトリ（`target.md` の担当用の限定 clone）の絶対パス／mode／merge-base の SHA／head の SHA（mode: local なら土台の HEAD と `local/` の各ファイルの sha256）。merge-base と head の40桁の SHA は両方ともこの欄に書く（基点など別の欄に書いた SHA は数えない）
- 受け取った入力: `refute-input/` の各ファイルと、`manifest.md` の sha256 との一致
- 依存の写し: 依頼本文が示す場所、`manifest.md` の lockfile のパスと sha256、`deps-files.sha256` と `manifest.md` の sha256 との一致（準備されていなければ「依存の写しなし」と `manifest.md` の理由）
- 終了状態: 完了／未確認を含む

## 軸ごとの結果

要対応の件数は下の要対応の節のその軸の見出しの数（同一原因は1件）、未確認の件数は未確認と理由の表のその軸の行数と同じにする（親のスクリプトが照合する）。

- Standards: 要対応 N 件、未確認 M 件（指摘や未確認が無くても 0 件と書く）
- Spec: 要対応 N 件、未確認 M 件（指摘や未確認が無くても 0 件と書く）

## 要対応（影響度の重い順）

要対応が無ければ「なし」。同一原因は1件にまとめ、含まれる候補 ID をすべて書く。見出しは `CAUSE-<n>`（採否一覧の同一原因と同じ）か候補 ID で始める。同一原因の影響度は、含まれる要対応の候補の採否一覧の影響度のうち最も重いもの（最小値）にする。

- 影響度: 0〜4
- 軸: Standards／Spec
- 起点: 今回の差分／基点から存在（基点から存在でも今回の明示要求が修正を求めるもの）

## 基点から存在する課題（別枠）

基点から存在（対象外）と判定した課題。候補 ID・場所・課題と影響・merge-base の証拠・今回の差分と要求との関係（悪化させていない、修正を求められていない根拠）。なければ「なし」。

## コード要求の対応表（反証で確定した行）

Spec 探索の対応表の全行は写さない。書くのは次の行だけで、親のスクリプトが要求の出典の一致で Spec 探索の対応表に重ねる。行を足さず、除かない。

- Spec 探索の対応表で「未充足」「未確認」のすべての行（1行ずつ。確定した状態 充足／未充足／未確認 と根拠）。候補の棄却だけを理由に「充足」へ変えない。
- Spec 探索で「充足」の行のうち「未充足」に変えた行（候補 ID を書く）。要対応と判定した候補の契約の出典と行範囲で重なる「充足」の行は必ず「未充足」にする。関連する要求としてだけ重なる行は判断で「未充足」にしてよい。まとめて書かれた行の一部が当たるときも、行全体を「未充足」にし、行を分けない。

要求の出典の欄は、Spec 探索の対応表の同じ行の出典をそのまま写す。未充足の行には採否一覧で要対応の候補 ID を、未確認の行は下の未確認と理由の表にも書く。書く行が無ければ、見出しの行と区切りの行だけの表にする。

| 要求の出典 | 状態 | 証拠または不足理由 | 候補ID |
|---|---|---|---|

## 未確認と理由

採否や充足を確定できなかった候補・要求、要求間の矛盾を、自由記述ではなく次の表に1件1行で書く。種別は「候補」（採否一覧で判定が未確認の候補。出典の欄に候補 ID を1つ）・「要求」（上の対応表で状態が未確認の行。出典の欄に対応表と同じ要求の出典を1つ）・「要求間の矛盾」（矛盾で未確認にした対応表の行。行ごとに1行）のどれか。判定が未確認のすべての候補と、上の対応表で状態が未確認のすべての行を載せる。理由（どのコード上の結論に、どの契約・資料が足りないか）・確かめる担当（例: 人）・不足箇所は空にしない。なければ「なし」。

| 要求の出典または候補ID | 軸 | 種別 | 理由 | 確かめる担当 | 不足箇所 |
|---|---|---|---|---|---|

## 判断を見送った事項

1件ごとに短い理由。なければ「なし」。

## 採否一覧（監査用）

両方の引き渡し用ファイルのすべての候補と、反証で追加した発見を載せる。任意の改善はここにだけ載せ、提案として扱わない。影響度は要対応にだけ 0〜4 を書き、それ以外は「なし」と書く。反証で追加した発見が無ければ、この節に「反証で追加した発見なし」と書く。

|---|---|---|---|---|---|
