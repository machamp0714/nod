## 要対応

反証が確定した要対応だけを影響度の重い順に、同一原因は1件（見出しの `CAUSE-<n>` と含まれる候補 ID）で載せる。全件を載せ、件数の上限で省略しない。問題は要対応の見出しの題、影響と場所は要対応の「影響」「場所」の欄から転記し、判定や影響度は変えない。なければ「なし」。

| ID | Severity（影響度） | 問題 | 影響 | 場所 |
|---|---|---|---|---|

Severity は共通規則の影響度から機械的に表示する: 0・1=Critical、2=High、3=Medium、4=Low。影響度の数値も併記する（例: `High（高）、影響度 2`）。任意改善・棄却・未確認は混ぜない。
