# 受け入れ確認の結果

## 担当と対象

- 役割: 受け入れ確認
- 定義名: code-reviewer-acceptance
- 担当 ID: （分かれば。分からなければ「不明」）
- モデル申告: （自分で分かる情報と出典。分からなければ「未確認」）
- 対象版: 対象リポジトリ（`target.md` の担当用の限定 clone）の絶対パス／mode／merge-base の SHA／head の SHA（mode: local なら土台の HEAD と `local/` の各ファイルの sha256）
- 受け取った入力: `acceptance-input/` の各ファイルと、`manifest.md`・`records.md` の sha256 との一致
- Activity・添付 Document・参照された記録・外部の正本の写し: `records.md` に書かれた取得時刻と指紋、取得不能とされた項目
- 終了状態: 完了／確かめられずを含む

## 行ごとの判定

対応表で「受け入れ確認担当」とされたすべての行を、対応表と同じ要求の出典で1行ずつ書く（行の欠落は無効な結果になる）。5つの部分は、それぞれ「確認済み／未充足／確かめられず」と根拠、または「対象外（要求が求めていない）」を書く。

### 行 <n>: <要求の出典>

- 要求の出典: （対応表と同じ）
- 対象版: （判定に使った head の SHA と、証拠が示す版。証拠が対象版との対応を示さなければそのこと）
- 判定: 確認済み／未充足／確かめられず
- 成果物の不変版の存在: 版を特定できる不変の写しがあるか
- 作業・手順の実施: 要求された作業・手順を行ったか
- 現在の配置: 配置先の観測が対象版を指しているか（不変版があることだけでは確認済みにしない）
- 外部の正本との内容の一致: 名指しされた外部の正本の写しと内容が一致するか
- 更新順序: 版履歴などの証拠で順序を確かめたか（取得時刻・指紋・ファイルの更新時刻だけでは確認済みにしない）
- 証拠: 使った写しと固定版（`records.md` の項目 ID、成果物の場所・指紋・記録の ID（Activity の ID と時刻、Document ID と行）・観測）
- 不足理由: 何が無く、何があれば確かめられるか（確認済みなら「なし」）
- 証拠にしなかった主張: 自己申告・チェック済みの印・過去の点数・反証の結論など（なければ「なし」）

## 判定に使った証拠

判定の根拠にした写しを、`records.md` の項目 ID（`activity:<id>`・`activity@<時刻>`・`document:<ID>`・`evidence/<n>`）ごとに1行ずつ漏れなく書く。使わなかった写しは書かない。限定 clone の固定版だけを使った行は、項目に「限定 clone」と書く。親は保存の直前にこの節の項目だけを取り直して固定時と比べる。なければ「なし」。
