実行はリポジトリルートで `bun reports/jev/evaluate.ts`。通常の自動テストからは実行されず、明示実行時だけ実 API に要求する。環境変数 `TYPESAFE_API_KEY` を優先し、未設定時だけ `~/.config/nod/env` の該当キーを読む。設定を実行・展開せず、キー・認証ヘッダー・外部エラー本文を結果へ出力しない。各要求は本文だけを state にし、Noul 一問、5秒上限、再試行なしで直列実行する。

全結果と測定時刻は [results.json](results.json)、問い・判定基準は `packages/core/src/ops/jev-client.ts` の `JEV_QUESTION` が正本。評価スクリプトは問いのみと判定基準付きの2候補、および閾値 0.3・0.5・0.7 を比較する。
